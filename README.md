# 🇱🇰 SynhalEES: Sinhala Linguistic & Cultural Alignment Benchmark

> **Measuring how authentically Large Language Models (LLMs) can speak, reason, and behave like a native Sinhala human.**

SynhalEES is the first multidimensional evaluation suite designed specifically for the Sinhala language and Sri Lankan cultural context. It spans a 15-dimensional spectrum ranging from sacred Pali texts, Buddhist ethos, and classical literature to day-to-day spoken nuances, SMS Singlish, Gen Z slang, and local humor.
